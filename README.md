# GoodSpeaker
A Preset for Phone Speakers made by me
**Tuned Especially for the Redmi Note 14 Pro 5G!** but You are free to modify the files on how you like it to be

# NOTICE: Only compatible with VIPERFX_RE and Viper4Android by likelikeslike

# Viper4Android installation
Please refer on the [Official Installation Guide](https://github.com/likelikeslike/ViPERFX_RE#installation) for Viper4Android FX app installation.

## Preset Files
- You can find them on the [RElease Page](https://github.com/nanerb25/GoodSpeaker/releases)
- Step 1: Open the Viper4Android ap
- Step 2: Click the Settings or Gear icon at the Top Right
- Step 3: Click "Import Preset" and select the preset file
- Step 4: After importing, Open the Presets menu and Select the Preset file you imported and done!
